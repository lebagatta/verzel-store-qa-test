# Relatório de Defeitos (Bug Reports)

## Status Geral
Durante a rodada de testes manuais realizada na interface da **Verzel Store**, **nenhum defeito crítico ou bloqueante foi identificado**. Todas as regras de negócio de cupons de desconto, limiar de frete grátis, limite de unidades e validações do formulário responderam estritamente de acordo com os critérios de aceite (CA01 ao CA11).

Caso sejam identificadas divergências nas etapas de testes automatizados de API ou integração E2E no Dia 2, os registros serão adicionados a este documento.
